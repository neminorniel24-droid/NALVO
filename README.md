# Nalvo

A local business directory for **Tamil Nadu and Kerala**. Owners list their business with category-specific details (fees, services, timings, location). Customers filter by state, district, category and distance. Supports English, Tamil and Malayalam.

> Status: early prototype.

## Features
- Business enrolment with category-specific questions
- State, district, category and keyword filters
- "Near me" distance sorting and Google Maps directions
- English / Tamil / Malayalam interface
- Light and dark theme, mobile-first

## Run locally
Open `index.html` in a browser. Without a backend, listings are stored in memory for the session only.

## Roadmap
- Public backend (database, sign-in)
- Per-listing shareable pages
- Verified badge and owner analytics
